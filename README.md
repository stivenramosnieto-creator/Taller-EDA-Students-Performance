 Taller EDA - Students Performance

## Descripción

Este proyecto presenta un análisis exploratorio de datos (EDA)
realizado sobre un conjunto de datos de rendimiento académico
de estudiantes.

## Herramientas utilizadas

- Python
- Pandas
- Matplotlib
- Google Colab

## Análisis realizado

El proyecto incluye:

- Exploración de datos
- Análisis de valores nulos
- Análisis de duplicados
- Limpieza de datos
- Transformación de variables
- Creación de un promedio académico
- Filtrado de datos
- Agrupaciones con `groupby()`
- Visualización de datos
- Análisis de correlaciones
- Conclusiones

## Dataset

El conjunto de datos contiene información sobre características
de los estudiantes y sus resultados en matemáticas, lectura y
escritura.
